📇 우리 아이 소개서 앱

장애가 있는 자녀를 둔 부모가 쓰는 "우리 아이 소개서" 웹앱을 만들어 줘. 새 담임, 활동지원사, 치료사, 돌봄 선생님에게 아이를 소개하는 한 장짜리 카드를 만드는 앱이야. [사용자] - 스마트폰을 주로 쓰는 부모. IT에 익숙하지 않으니 설명 없이도 쓸 수 있어야 해. [입력 항목] - 기본 정보: 이름(또는 애칭), 사진, 나이, 한 줄 소개 - 좋아하는 것 / 싫어하는 것 - 의사소통 방식: 어떻게 표현하는지, 어떻게 말해 주면 잘 이해하는지 - 힘들 때 보이는 신호와 진정시키는 방법 - 식사, 화장실, 이동 등 일상에서 도움이 필요한 부분 - 건강 정보: 복용 약, 알레르기, 발작 등 주의사항과 대처법 - 꼭 지켜 주세요 (안전 관련 당부) - 비상 연락처 - 부모가 직접 이름을 붙이는 추가 항목 모든 항목은 선택 입력이고, 비워 둔 항목은 카드에 나오지 않게 해 줘. 항목마다 무엇을 쓰면 좋을지 예시 문장을 흐리게 보여 줘. [소개 카드] - 입력한 내용이 A4 한 장 분량의 따뜻하고 읽기 쉬운 카드로 정리돼. - 받는 사람이 1분 안에 읽을 수 있게, 안전과 건강 관련 내용이 가장 눈에 띄어야 해. - "이미지로 저장" 버튼과 "인쇄" 버튼을 넣어 줘. - 카드 색상 테마를 3~4가지 중에 고를 수 있게 해 줘. - 받는 사람에 따라 보여 줄 항목을 켜고 끌 수 있게 해 줘. (예: 체험학습 선생님에게는 건강 정보와 연락처만) [기술 조건] - 파일 하나로 된 모바일 우선 웹앱, 로그인과 서버 없음. - 입력 내용은 이 기기에만 자동 저장되고 외부로 전송되지 않아. 이 사실을 화면에 한 줄로 안내해 줘. - 사진은 저장 전에 작게 줄여 줘. - 글자는 크게, 버튼은 손가락으로 누르기 쉽게, 색 대비는 충분하게. - 처음 열면 가상의 아이 "하늘이"의 예시가 채워져 있고, "내 아이 정보로 시작하기"를 누르면 비워지게 해 줘. - 모든 화면 문구는 부드러운 한국어 존댓말로.

🗣️ 맞춤 그림 의사소통판 앱

말로 표현하기 어려운 아이가 그림 카드를 눌러 의사를 전하는 "맞춤 그림 의사소통판" 웹앱을 만들어 줘. 부모가 우리 아이가 실제로 쓰는 말과 사진으로 카드를 직접 만드는 것이 핵심이야. [아이가 쓰는 화면] - 큰 그림 카드가 격자로 보이고, 카드를 누르면 카드의 말을 한국어 음성으로 읽어 줘. - 누른 카드는 잠깐 커지거나 색이 바뀌어서 눌렸다는 것이 분명히 보여야 해. - 위쪽에 문장 띠가 있어서 누른 카드가 순서대로 쌓이고, "말하기" 버튼을 누르면 이어서 읽어 줘. "지우기" 버튼도 넣어 줘. - 분류 탭: 기본 표현, 먹기, 놀이, 기분, 몸·아파요, 사람, 장소 - "네", "아니요", "도와주세요", "그만"은 어느 화면에서든 항상 보이게 고정해 줘. - 아이가 실수로 다른 곳으로 나가지 않게, 이 화면에는 설정 버튼을 작게 숨겨 줘. [부모가 쓰는 편집 화면] - 설정 버튼을 2초간 길게 눌러야 들어갈 수 있어. - 카드 추가, 수정, 삭제, 순서 바꾸기 - 카드 한 장 = 그림 + 글자 + 읽어 줄 말 (읽어 줄 말은 글자와 다르게 쓸 수 있어) - 그림은 휴대폰으로 사진을 찍거나 앨범에서 고르거나, 이모지 중에서 선택해. - 분류 추가와 이름 변경 - 한 화면의 카드 수 조절 (2칸, 3칸, 4칸), 말하는 속도 조절 - 카드 전체를 파일로 내보내고 다시 불러오는 백업 기능 [기본 제공 카드] - 처음부터 분류마다 6~8장씩 이모지로 된 기본 카드가 들어 있게 해 줘. (예: 물 주세요, 배고파요, 화장실, 아파요, 안아 주세요, 더 하고 싶어요, 싫어요, 집에 가요) - 그림은 이모지나 직접 그린 단순한 도형만 쓰고, 외부 그림 자료는 가져오지 마. [기술 조건] - 파일 하나로 된 웹앱, 로그인과 서버 없음, 인터넷이 끊겨도 동작해야 해. - 음성은 브라우저에 내장된 한국어 음성 읽기 기능을 써 줘. - 카드와 사진은 이 기기에만 저장돼. 사진이 많아져도 괜찮도록 작게 줄여서 용량이 넉넉한 저장 방식으로 보관해 줘. - 휴대폰과 태블릿 모두, 세로와 가로 화면 모두에서 카드가 화면을 꽉 채우게 해 줘. - 배경은 단순하게, 색 대비는 뚜렷하게, 움직이는 효과는 최소로.
